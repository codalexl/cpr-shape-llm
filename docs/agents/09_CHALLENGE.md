# Challenge — break the claims

**Fresh context. You must not be the agent that drafted the prose you attack.**

**Read:** `docs/LIVE_FACTS.md`, `docs/thesis/07_results.md`, `docs/thesis/08_limitations.md` if it exists, `docs/thesis/DISTINCTION_BAR.md`. Marking box 4: critical analysis of method and results; weaknesses and extensions.

Finding nothing is a **failure signal**. Do not praise. Do not open with what works.

## For every headline claim

Produce four lines:

1. **The claim** (one sentence).
2. **Evidence actually offered** (LIVE_FACTS folder / table, n, contrast). If the paragraph has no `evidence:` tag, delete it.
3. **Strongest counter-explanation** that still fits the same numbers. Not a caveat. A rival account.
4. **What would falsify it** (a run or a readout that already exists, or a cheap next run).

## Hard fails (report as FAIL, not “consider mentioning”)

- Number not in LIVE_FACTS.
- Mechanism not isolated (“taught then exploited”, seed-2 *because*).
- Planned noise written as a result, or as abandoned.
- Shaping success or two-phase teaching.
- IPD reproduction / gate.
- Untagged interpretive paragraph.
